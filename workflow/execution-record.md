# 台灣夜市文化與小吃｜流程與執行紀錄

## 繳交資訊
標題格式：學校 學號 系級 姓名 台灣夜市文化與小吃（請自行填寫身分資訊）

## 主題與成果
主題介紹：以台灣夜市為例，帶初學者理解夜市與地方生活、多樣的發展路徑、三個夜市案例及幾種小吃。Wiki 為 LLM 輔助整理的靜態 Markdown 檔，共 ingest 七篇網頁摘要；簡報為獨立 HTML，附 Wiki 條目和原始來源。雙擊 HTML 即可在瀏覽器使用。

## 先討論、後生成
使用者提出料理或觀光方向，從建議題目中選擇「台灣夜市文化與小吃」。之後確定以初學者為對象，安排文化脈絡、地方案例與小吃。這份紀錄不虛構未發生的問答。

## Loop / graph
選題與界定範圍 → 蒐集資料（逐篇記錄來源、日期與摘要） → 查詢／整合 Wiki 條目 → 檢查證據、範圍與時效 → 產生簡報 → 對照 Wiki 與測試操作 → 完成

- 若來源無法支持某句話：返回「蒐集資料」或「整合條目」，縮小論述範圍、補來源，再檢查。
- 若簡報內容與 Wiki 不符：返回 Wiki 查詢與簡報生成節點，修改後再核對。
- 若互動或排版有問題：返回 HTML 修改節點，再測試。
- 目的：先讓資訊可追溯、避免以偏概全，再讓簡報容易閱讀和操作。這是本次以人工指揮 LLM 完成的工作流程；並未實作自動化 agent 或 graph 程式。

## 本次實際執行與檢查
日期：2026-11-23。查閱七篇資料，整理為 W1–W7；簡報 10 頁，每頁（封面除外）標明 Wiki 與來源代號。來源與條目請見「夜市文化-LLM-Wiki.md」。

**具體問題與調整：** 資料檢查時，發現交通部觀光署中文《夜市之旅》對饒河街的「第一」用語限於臺北，其英文版使用台灣範圍的描述；兩者範圍不同，不足以不經進一步考證就寫成全台第一。另臺北畫刊記述艋舺廟口案例，高雄旅遊網則記錄市場轉型及攤販集結等不同路徑，因此不能將單一案例擴寫為「所有夜市都起源於廟口」。最終簡報刪去未必要的第一名說法，並明確寫出多種路徑。

**操作檢查：** 使用 JavaScript 的模擬文件環境執行 HTML 內的程式：初始頁、下一頁、方向鍵返回、末頁邊界、答案顯示、10 個簡報區塊與 7 個來源連結均通過。另外在內建瀏覽器開啟首頁，實際點擊下一頁，確認頁碼由 1 / 10 變為 2 / 10。尚未做完整的跨裝置版面或無障礙驗收。

## 反思
- **哪個節點容易出錯？** 本次實際發現的問題集中在「來源解讀與概括」：地理範圍、個案和普遍結論容易混淆。只記錄到這一類問題，沒有足夠的多次執行次數可以統計哪個節點最常出錯。
- **檢查往前移到哪裡？** 在寫投影片前，先於整理 Wiki 時標記來源所指的地方、時間與案例範圍，並排除無證據的「全部」「第一」等絕對說法。
- **是否修改 workflow？** 有：在「Wiki 整理」和「簡報生成」之間增加證據範圍檢查，讓有問題的概括先回到來源查核，而不是等投影片完成才全面重寫。後續更新來源時仍需重新確認。
